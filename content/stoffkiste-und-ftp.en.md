# Material Box & FTP

## \[category] Material Box

In the **Material Box**, you will find an extensive collection of learning materials for various modules.

If you find any errors or want to contribute something, you can create an issue or a pull request on [GitHub](https://github.com/fsr/Stoffkiste).

> Access all materials here: [stoffkiste.ifsr.de](https://stoffkiste.ifsr.de)

## \[folder_open] FTP Server

Our **FTP server** provides access to a wide range of study materials:
- Past exams
- Exercise sheets & solutions
- Lecture notes
- Cheat sheets

You can access the files with any FTP client (e.g., FileZilla) or via the browser. However, access is only possible from within the TU Dresden university network — e.g., via eduroam or computers within the campus network. If you want to access it from outside, you need a VPN connection to TU Dresden.

> Access here: [ftp.ifsr.de](https://ftp.ifsr.de/)
